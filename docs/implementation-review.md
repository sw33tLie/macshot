## Streaming GIF follow-up

- Replaced the animation-wide ImageIO destination and removed `GifskiExporter`. `GIFEncoder` quantizes one opaque image at a time with ImageIO, checks finalization, and streams its palette/LZW image block into a GIF89a container. It retains only the previous pixels and pending encoded frame. The container uses local palettes, actual presentation-time delays, a full first frame, changed rectangles for later frames, and unchanged-pixel coalescing. Long holds split at the format's 16-bit delay limit. Format reference: [GIF89a specification](https://www.w3.org/Graphics/GIF/spec-gif89a.txt).
- `GIFExporter` reads the processed edit timeline at an explicit output cadence, using sample timestamps and the final timeline duration. Cuts/speed/freezes are applied even without overlays; sparse sources keep their static tails; the same upright geometry/effect snapshots used by MP4 are applied. It validates setup/read completion, observes cancellation between frame operations, and only atomically publishes a complete result. No Homebrew executable, accumulated PNG scratch directory, or argument vector proportional to duration is needed.
